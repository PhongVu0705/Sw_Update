Update Guide

    • 1

      Connect to your tool

      Plug the tool into the PC, select its COM port and press Connect.

    • 2

      Delete log

      Clear the old entries in the terminal so the new run starts clean.

    • 3

      Press update

      Choose the FW you want to update.

    • 4

      Choose firmware you want to update

      Browse and select the firmware file for your tool.

    • 5

      After completed, press 3 dots button

      Once the update has finished, open the ⋮ (three dots) menu.

    • 6

      Download the CSV log file

      Save the session log as a CSV file for your records.
